# Contributing to FindingNemos

FindingNemos is an independent, Zig-first project for local AI governed execution.

## Getting Started

1. Ensure you have the latest stable Zig toolchain.
2. Clone the repository and run `zig build`.
3. Read `AGENTS.md` for project doctrine and non-negotiable standards.

## Submitting Pull Requests
- Ensure `zig build test` passes.
- Ensure `scripts/smoke.sh` passes.
- Adhere to the operator-truth doctrine: no fake capability claims.
